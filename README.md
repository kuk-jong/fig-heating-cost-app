# Fig Greenhouse Heating Cost App

정적 웹앱으로 구현한 무화과 가온재배 난방비 예측 도구입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 실행됩니다.

## 계산 구조

- 온실 외피면적: 폭, 길이, 측고, 동고 기반 단동 비닐하우스 형상
- 난방디그리아워: `sum(max(T_set - T_out, 0))`
- 유효 열관류율: `피복재 U값 × 보온커튼 보정계수`
- 기간 난방부하: `외피면적 × 유효 열관류율 × 난방디그리아워 / 1000`
- 예상 난방비: `난방부하 / 난방효율 × 전력단가`

## CSV 입력

기상청 ASOS 시간자료를 정제한 CSV를 업로드할 수 있습니다. 다음 필드 중 일부를 인식합니다.

- 시간: `tm`, `date`, `datetime`
- 월: `month`
- 기온: `ta_c`, `ta`, `temperature`, `temp`
- 지역: `region`, `stn_name_kma`, `stn_name`

CSV가 없을 때는 앱 계산 구조 확인을 위한 예시 난방디그리아워 프로파일을 사용합니다.
