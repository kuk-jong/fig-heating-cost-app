# 무화과 가온재배 3D 경영의사결정지원시스템 Framework

## 목표
기존 fig-heating-decision-app의 경영의사결정 요소와 fig-heating-cost-app/v2-3d의 현실형 3D 온실을 결합한다. 기존 두 앱은 보존하며 본 폴더를 신규 통합 앱으로 개발한다.

## 개발 원칙
1. Single Source of Truth: 온실 입력값 하나를 계산과 3D가 공동 사용한다.
2. 원본 보존: 기존 앱 계산식과 3D 앱은 직접 변경하지 않는다.
3. 계산/표현 분리: domain -> calculation -> presentation -> 3D 순으로 의존한다.
4. 변경 시 FRAMEWORK.md, UML.md, CHANGELOG.md를 함께 갱신한다.
5. 계산식 변경은 CHANGELOG에 별도 표시하고 검증 항목을 남긴다.

## 기능 구조
### A. 농가/분석 조건
- 지역: 기본 해남군
- 재배방식: 여름재배(관행) / 겨울재배
- 10년 기상 CSV 선택 입력

### B. 온실
- 1동 폭, 길이, 측고, 동고, 연동 수
- 기본 8m x 42m, 측고 2.5m, 동고 4.0m, 3연동
- 온실면적 = 1동 폭 x 길이 x 연동 수
- 방풍벽: 없음 / 한쪽 / 양쪽 표준 / 양쪽+보강
- 기밀도: 매우 우수 / 양호 / 보통 / 취약 / 매우 취약
- 피복 및 보온 조건
- 3D: 외부 / 내부 / 골조, 사선 / 정면 / 측면 / 평면

### C. 생산 계획
- 겨울재배 기본(300평): 여름 1,219kg, 겨울 635kg
- 여름재배 기본(300평): 여름 2,500kg
- 면적비례 자동 환산
- 판매단가: 겨울재배 기본 여름 6,400원/kg, 겨울 30,000원/kg
- 여름 경영비율: 겨울재배 43%, 관행 40%

### D. 시설투자/감가상각
300평 기준 기본값:
- 이중비닐 공사 957만원 / 10년
- 보온커튼 공사 840만원 / 10년
- 이중비닐 피복재 24만원 / 3년
- 다겹보온커튼 자재비 248만원 / 5년
현재 면적에 비례하여 자동 환산하며 사용자가 수정 가능하다.

### E. 난방/환경
- 목표온도
- 보온등급/U값
- 연료 및 단가
- 난방효율
- 기밀도 보정: 0.90 / 1.00 / 1.10 / 1.25 / 1.40
- 방풍벽 보정: 1.00 / 0.97 / 0.94 / 0.90
- 기상자료 기반 난방디그리아워
- 외피면적, 난방부하, 난방비

### F. 경영분석
- 여름 매출/경영비/순이익
- 겨울 매출/난방비/시설 감가상각/순이익
- 연간 매출/비용/순이익
- 겨울재배 추가효과
- 목표온도/연료단가/보온등급 민감도

## 데이터 흐름
User Input -> Validation -> GreenhouseModel / ProductionPlan / InvestmentPlan / HeatingCondition -> ClimateData -> HeatingCalculator -> ProfitabilityCalculator -> DecisionResult -> Dashboard + Greenhouse3D + CSV

## 3D 연결 규칙
GreenhouseModel의 width, length, sideHeight, ridgeHeight, spanCount, windbreak, coverCondition을 그대로 Greenhouse3D에 전달한다. 3D 전용 별도 치수값을 만들지 않는다.

## 검증 체크
- 1연동/3연동 면적 계산
- 동고 > 측고 검증
- 300평 기준 생산량/투자비 면적비례 환산
- 관행 선택 시 겨울 매출/난방/감가상각 0
- 기밀도와 방풍벽 계수가 난방부하에만 반영되는지 확인
- 3D 치수와 계산 치수 일치
- 모바일/데스크톱 화면 확인
